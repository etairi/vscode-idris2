# Changelog

All notable changes to the "Idris 2" extension (`vscode-idris2`) are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/); the extension's version is
independent of Idris 2 releases (`docs/ROADMAP.md` §7.4).

## [Unreleased]

### Added

- Project skeleton, built to `docs/ARCHITECTURE.md` §2: manifest with the `idris2`, `lidr` and
  `ipkg` language contributions, the `Idris 2: Show Output` command and the "Idris 2" log
  channel, the TypeScript 6 / esbuild / eslint / mocha / `@vscode/test-cli` harness, a GitHub
  Actions workflow, and the design documents under `docs/`.
- M0, language foundation:
  - TextMate grammars for Idris 2 (`source.idris2`, generated from
    `syntaxes/src/idris2.grammar.mjs` and written from the compiler's lexer and parser),
    bird-track literate Idris (`source.idris2.literate`) and `.ipkg` files (`source.ipkg`).
  - Language configurations: comments, brackets, auto-closing (including `{-` → `{- -}`), a
    word pattern that keeps `?holes` and primes whole, and Enter rules (including `> `
    continuation in `.lidr`), generated by `scripts/build-language-configuration.mjs`.
    Indentation folding for `.idr`.
  - Snippets for Idris 2 (16) and `.ipkg` (2).
  - Syntactic Expand Selection for `.idr` and `.lidr`.
  - The Help commands `Idris 2: Open Settings` and `Idris 2: Open Idris 2 Documentation`.
  - Editor defaults for `[idris2]`/`[lidr]`: tab size 2 with spaces, semantic highlighting on,
    no ambiguous-Unicode boxes, and `editor.wordSeparators` without `'` and `?`; LF line
    breaks for new `.lidr` files (`files.eol`), which idris2 needs.
  - The semantic token types `module` and `postulate` (declared for later milestones).
  - Support for Restricted Mode (untrusted workspaces).
- M0, internal foundations for later milestones:
  - `core/positions.ts` with the coordinate conventions of the compiler.
  - `backend/types.ts` and `NullBackend`.
  - The single document-selector rule (`project/literate.ts`, context key
    `idris2.isIdrisDocument`).
  - A goal-panel stub bundle (`dist/goalPanel.js`).
- M0, engineering:
  - Grammar tests: snapshots, scope assertions, a timing check, a real-world corpus test at
    pinned commits, a check that `.idr` code tokenises the same on bird-track lines (also with
    prose lines between them), and an opt-in comparison with the Idris 2 lexer.
  - Integration tests for activation, languages, editor behaviour, documents and selection
    ranges.
  - A fake `idris2` for the IDE protocol handshake.
  - `scripts/check-fixtures.mjs` (fixtures and snippet expansions against `idris2`), and
    `scripts/deps-graph.mjs` for the ROADMAP §4 graph.
  - CI for ubuntu, macOS and Windows, with `vsce package` on ubuntu; green on all three since
    run 36327327811 (2026-09-27).
  - The manual checklist `docs/checklists/M0.md`.
