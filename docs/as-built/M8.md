## Decisions

The user's (ROADMAP §9, 2026-10-30):

1. **The Query box and the lenses send expressions, `:t` and `:doc`, and refuse every other command
   before sending** (`replCommand.ts` `queryRefusal`), on the shared `eval` session. No session of their
   own, which would be one more compiler process.
2. **Q23 covers the Query box and a single Run. Run all asks first** and says how many lines it runs.

The author's, within ROADMAP M8:

3. **A project's REPL opens on the file** (*Deviations*).
4. **`rlwrap` when it is on `PATH`.** ROADMAP counted on history and line editing "for free"; the REPL has
   neither [live], and a pseudo-terminal of our own is out of scope. Only fully qualified `PATH` entries
   are searched, in the environment the terminal gets. Not on Windows. There is no setting.
5. **What is typed is one line.** Line breaks become spaces, so that text cannot run a second command,
   and text with a control character is not typed (M1's rule for terminals, relaxed only by the Enter
   that ends the line). The user runs what they select: `:exec` works, as it does at the prompt.
6. **One REPL per root, on the file it started on.** A second Open REPL shows it. It does not `:l` the
   active file: that would drop the user's `:let` definitions unasked.
7. **The REPL is not a session.** It has no time limits, no limit counts it, Stop Backend leaves it
   alone, and it builds into the project's own build directory. `isTransient`: a window reload does
   not bring back a terminal nothing here knows.
8. **Query answers go to an output channel**, `Idris 2 Query`, which keeps what was asked, shown without
   taking the focus: `:doc` is several lines, and a notification is one.
9. **A lens saves first**, under `idris2.checking.saveBeforeAction`, as the editing commands do: the
   compiler answers for the file on disk, and the answer goes into the text in the editor. Found by the
   author's review: without it, an unsaved edit gave a stale answer written beside new text.
10. **`:type` passes with `:t`:** it is the same command of the compiler [live].
11. **An answer is a comment whatever it says:** each of its lines starts with the line's prefix and
    `--`, its control and format characters written out. Running a line again replaces its answer, whose
    further lines start `-- > ` so that the comments below it are kept (review 1, H6).
12. **An error is not written** into the file. Run all counts those lines and shows the first.

## Deviations from ROADMAP §5 M8

- **`idris2 --find-ipkg <file>`, not `idris2 --repl <ipkg>`.** After `--repl`, `:r` answers `No file can be
  reloaded`, so the planned reload on save cannot work, and the prompt is the package's last module, not
  the user's file [live]. D4's "never `--find-ipkg`" is about sessions, which get absolute paths from any
  directory: from a subdirectory it breaks relative loads (F13). Here the terminal starts in the `.ipkg`'s
  directory, with a path relative to it, the case F13 says loads.
- **History and line editing are not free** (above).
- **Completion in the Query box** is `IdrisBackend.completions`, the `check` session's `:repl-completions`
  (a passive query), not the `eval` session's: M3's rule keeps that session to evaluations, and the
  existing path has its warm-up and filtering.
- **A QuickPick, not an input box:** VS Code's input box has no completion.
- **The lenses are registered without regard to the backend:** over idris2-lsp a Run says that evaluation
  needs IDE mode (M5's rule, never a silent no-op). Finding the backend would mean classifying every
  document that opens, for a lens few files have.
- **ROADMAP's "With M2" acceptance item is manual:** it needs two compilers at once (*Acceptance*).

  plain lines.

  Nat -> Nat`; `:doc double` answers three lines; an undefined name is the `:error` answer with a source

## Limitations

- **The REPL takes one line at a time**, so a selection over several lines works only as one line.
- **A running program reads what is typed**, a `:r` on save included.
- **`:let` definitions** live in the REPL: Query and the lenses, which use the evaluation process, do not
  see them.
- **A folder with several `.ipkg` files:** when the compiler would take another one than the extension
  found, the REPL does not start (review 1, H7; U2.7 [gh]).
- **`:doc` of an operator** at the cursor is sent as it stands, without the parentheses `:doc` may want.
- **Run all saves once**, before its first line; an edit during the run leaves the answers unwritten, and
  they are shown instead.
