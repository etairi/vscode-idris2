# M4 manual checklist

This is the "Manual" test layer of `docs/ARCHITECTURE.md` §12 for milestone M4 (`docs/ROADMAP.md`
§5). Work through it on the packaged extension, with the real `idris2`, before tagging M4. It
checks what the automated suites cannot see: keys pressed on a real keyboard, what the light bulb,
the QuickPicks, the progress notification, the status bar and the Holes view look like, and that
compiler text in them stays text.

**Setup.** As for M3: a throwaway profile under short `/tmp/vi2-*` paths (F17), with
`--shared-data-dir`, and `code` standing for
`"/Applications/Visual Studio Code.app/Contents/Resources/app/bin/code"` on macOS. Work on a copy
of the fixtures. `pgrep -fl -- '--ide-mode.*vi2-m4-ws'` lists this window's compiler processes.
Kill only the VS Code processes started this way, and delete `/tmp/vi2-m4` and `/tmp/vi2-m4-ws`
at the end.

```sh
npm run package                                    # → vscode-idris2-<version>.vsix
cp -R test/fixtures/workspaces /tmp/vi2-m4-ws
V=(--user-data-dir /tmp/vi2-m4/u --extensions-dir /tmp/vi2-m4/e --shared-data-dir /tmp/vi2-m4/s --disable-telemetry)
code "${V[@]}" --install-extension vscode-idris2-*.vsix
code "${V[@]}" /tmp/vi2-m4-ws/broken
```

1. **Light bulb and one undo step.** Trust the folder and open `Clean.idr`. With the cursor on
   `?vlen_rhs` (line 8) the light bulb offers Proof Search, Intro, Refine Hole…, Make Lemma, Make
   With and Make Case; on `xs` of line 8 Case Split; on `append` (line 5) Add Clause and Generate
   Definition; on `module` nothing of this extension. **Case Split** from the light bulb on `xs`
   gives `vlen [] = ?vlen_rhs_0` / `vlen (x :: xs) = ?vlen_rhs_1`; one **Undo** (Cmd+Z / Ctrl+Z)
   brings back the line and leaves the file unmodified (no dot on the tab). Repeat with Add
   Clause, Make With, Make Case (`vlen xs = (case _ of` and, under it, `case_val => ?vlen_rhs)`) and
   Make Lemma (`vlen_rhs : Vect n a -> Nat` above `vlen`, and `vlen xs = (vlen_rhs xs)`): one undo
   each.
2. **Intro and Refine.** **Idris 2: Intro** on `?vlen_rhs` shows a QuickPick of `0` and
   `S ?vlen_rhs_0`; Escape changes nothing, choosing the second writes `vlen xs = (S ?vlen_rhs_0)`
   (an answer of more than one token goes in parentheses). Undo. **Idris 2: Refine Hole…** asks for
   an expression; `S` gives `vlen xs = (S ?vlen_rhs_0)`. Undo. Open `Ambig.idr`, Refine Hole… on
   `?g_rhs` with `foo`: a QuickPick of `Ambig.A.foo ?g_rhs_0` and `Ambig.B.foo ?g_rhs_0`; the one
   chosen is written qualified, in parentheses (`g = (Ambig.A.foo ?g_rhs_0)`). Undo.
3. **Cycling and the status bar.** In `Clean.idr` run **Proof Search** on `?vlen_rhs`: `0`, and the
   status bar shows `↻ next (1)`. Click it: `1`, `↻ next (2)`; **Idris 2: Next Result** gives `2`.
   Undo once: `1` again, and the status bar item disappears; Next Result now says the search
   ended and sends nothing (the protocol trace, `idris2.trace.protocol`, shows no request). Revert
   the file. **Generate Definition** on `append` inserts two clauses after its declaration; run it
   again with the cursor still on the declaration: the three-clause alternative replaces them.
   Revert, run Generate Definition on `append` once more, then **Idris 2: Next Result**: the same
   three-clause alternative. Revert. In `Edits.idr`, Proof Search on `?pair_rhs` gives `(x, y)`; Next Result says there are
   no more results and the status bar item goes. With `"files.autoSave": "afterDelay"` in the user
   settings, Proof Search on `?vlen_rhs` again and wait 3 s: the file is saved, `↻ next (1)` stays
   and Next Result gives `1`; Undo ends the cycle, and the next auto-save checks the file.
   Remove the setting. Proof Search once more, then press Save yourself: the file is checked and
   `↻ next (1)` goes.
4. **Failures in words.** In `Plain.idr`, Case Split on the `n` of `f n = n` says that this line
   has no hole to split on, and the protocol trace shows no `:case-split`. In `HoleErr.idr` (it has
   a type error), Add Clause on `before` says that the file did not load cleanly — fix the first
   error and save — and sends nothing; Make Lemma on `?after_rhs` still makes its lemma (undo).
   With the cursor on `module` in `Clean.idr`, Make Lemma says to put the cursor on a hole. No
   notification contains a link.
5. **Add Missing Cases.** Open `Part.idr`: the coverage error on `g` has a quick fix **Add Missing
   Cases** in its light bulb and in the Problems view; it inserts `g (S _) = ?g_missing_case_1`
   under `g 0 = 0`, before the blank line. Undo.
6. **Literate files.** Open `Lit2.lidr`: Case Split on `xs` of `> vlen xs = ?vlen_rhs` gives two
   clauses, each starting with a single `> `. Undo. On `n` of `> half n = ?half_rhs` (below the line
   `> `) Case Split is refused with an explanation, and the protocol trace shows no `:case-split`.
7. **Save before an action** (`idris2.checking.saveBeforeAction`). Type a space in `Clean.idr` and
   delete it again (the tab shows unsaved changes), then Proof Search on `?vlen_rhs`: with the
   default `always` the file is saved first. Set it to `prompt`: a modal question names the file and
   offers Save; Cancel runs nothing and leaves the file unsaved. Set it to `never`: the command asks
   you to save first. Remove the setting. While a Proof Search runs, a progress notification offers
   Cancel (for a fast search it may close before you can click).
8. **The Holes view.** Open `/tmp/vi2-m4-ws/holes` in the window (File → Open Folder, trust it)
   and open `Main.idr`. The activity bar shows **Idris 2** with the Holes view: `Base.idr` with
   `?todo  Vect (S n) a` and under it `0 n : Nat`, `0 a : Type`, `1 x : a`, `xs : Vect n a`;
   `Main.idr` with `?todo  Nat` and `?size_rhs  Nat`; the badge reads 3. Clicking a hole opens its
   file with `?name` selected. Insert two empty lines at the top of `Main.idr` without saving:
   clicking `?todo` still selects it. Set `idris2.holes.showInSideBar` to `false`: the view goes;
   remove the setting. Close both editors, split the editor, open `Main.idr` and `Base.idr` side
   by side and run **Developer: Reload Window**: the view lists the holes of both files. In a window
   of a folder without Idris files (`/tmp/vi2-m4-ws/loose-file/`
   has some, so use an empty folder) the Idris 2 icon does not appear.
9. **Holes without the compiler.** In `Main.idr`, **Idris 2: Next Hole** / **Previous Hole** jump
   from hole to hole and wrap around, also to a `?new` typed but not saved. **Idris 2: List Holes**
   shows the holes of Main first, then Base's, each with its type; choosing one selects it.
10. **Keyboard shortcuts and Show Keybindings** (ROADMAP §9 Q5). With the default scheme, on macOS
    **Control+C** followed by **Control+C / A / L / W / M / S / N / G / I / R / [ / ]** runs Case
    Split, Add Clause, Make Lemma, Make With, Make Case, Proof Search, Next Result (of either
    cycle), Generate Definition (Next Definition while its result is being cycled), Intro, Refine Hole…, Previous
    Hole and Next Hole in an Idris editor; on Linux the same after **Ctrl+Alt+I**. Try `[` and `]`
    also with a keyboard layout that needs Option/AltGr for them (not tried before M4, [open]).
    **Idris 2: Show Keybindings** (also in the Idris 2 menu's Help group) opens a read-only list of
    exactly these and M3's `T`, `D`, `E`; switch the scheme to `none` in the user settings: the
    open list says there are none and how to choose a scheme, and no shortcut runs.
11. **Restricted Mode.** Open `/tmp/vi2-m4-ws/broken` in a new window and choose **Don't Trust**:
    no light bulb of this extension; the editing commands and List Holes are not in the Command
    Palette (a key reports that nothing runs in Restricted Mode); Next Hole and Previous Hole work;
    the Holes view says the compiler does not run in Restricted Mode; `pgrep` finds nothing.
