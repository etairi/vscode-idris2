# M5 manual checklist

This is the "Manual" test layer of `docs/ARCHITECTURE.md` §12 for milestone M5 (`docs/ROADMAP.md`
§5). Work through it on the packaged extension, with a real `idris2-lsp`, before tagging M5. It
checks what the automated suites cannot see: what the status item, the QuickPick and the
notifications look like, the server's answers in the editor, and that server text in them stays
text.

**Setup.** A throwaway profile under short `/tmp/vi2-*` paths (F17), with `--shared-data-dir`, and
`code` standing for `"/Applications/Visual Studio Code.app/Contents/Resources/app/bin/code"` on
macOS. Work on a copy of the fixtures. A server installed by pack outside `PATH` needs
`PACK_BIN_DIR` in the environment VS Code starts with (here
`$HOME/.local/share/pack/bin`). `pgrep -fl idris2-lsp` lists the server's processes (pack's
wrapper, its launcher and the Chez process). Kill only the VS Code processes started this way, and
delete `/tmp/vi2-m5c` and `/tmp/vi2-m5c-ws` at the end.

```sh
npm run package                                    # → idris2-language-tools-<version>.vsix
cp -R test/fixtures/workspaces /tmp/vi2-m5c-ws
V=(--user-data-dir /tmp/vi2-m5c/u --extensions-dir /tmp/vi2-m5c/e --shared-data-dir /tmp/vi2-m5c/s --disable-telemetry)
code "${V[@]}" --install-extension vscode-idris2-*.vsix
PACK_BIN_DIR=$HOME/.local/share/pack/bin code "${V[@]}" /tmp/vi2-m5c-ws/lsp-ipkg
```

1. **`auto` keeps IDE mode.** Trust the folder and open `src/Clean.idr`. The status reads
   `Idris 2 0.8.0 · IDE mode · …`, and `pgrep -fl idris2-lsp` lists nothing.
2. **The server serves the package.** In the user settings set `"idris2.toolchain.lspPath"` to the
   server (`$HOME/.local/share/pack/bin/idris2-lsp`) and `"idris2.backend.mode": "lsp"`. The status
   reads `Idris 2 0.8.0-1c630e67c · idris2-lsp`; one server runs. **Show Setup Information** names
   the server, the `idris2` beside it and the pair verdict *compatible*.
3. **Hover, saved and unsaved.** Hover over `xs` on line 8: `xs : Vect ?_ ?_` in a code block,
   no link. Type a character at the end of the file without saving: the hover shows nothing, and no
   notification appears; undo the character: the hover answers again without a save.
4. **The server's other answers.** Completion on a new line after `vl` offers `vlen` with its
   type; Go to Definition on `Vect` opens the prelude's source; the Outline lists the declarations;
   **Idris 2: Show Language Server Output** shows the server's `LOG INFO:…` lines.
5. **Editing over the server.** On `?vlen_rhs`: Proof Search gives `vlen xs = 0`, Next Result `1`;
   undo. Intro offers `0` and `S ?vlen_rhs_0`; the second is written `(S ?vlen_rhs_0)`; undo. Case
   Split on `xs` and Make Lemma give what M4's checklist lists for IDE mode, one undo each. Refine
   Hole… with `foo` in `Ambig.idr` says that idris2-lsp reports no alternatives for an ambiguous
   name, and changes nothing. In `Part.idr` the coverage error's light bulb offers Add Missing Cases
   (the extension's) and the server's `QuickFix: Add partial annotation`, both as text.
6. **The Holes view** lists `vlen_rhs` of `Clean.idr` with its premises; a click jumps to it.
7. **Switch Backend.** **Idris 2: Switch Backend…** offers IDE mode (marked as not serving) and
   idris2-lsp (serving); choose IDE mode: the status reads `· IDE mode`, hovers come from the
   compiler again, the Problems view shows IDE mode's problems only. **Switch Backend… → Follow the
   Setting** goes back to idris2-lsp.
8. **A file without an `.ipkg`.** Open `/tmp/vi2-m5c-ws/loose-file/Hello.idr` (File → Open): a
   notification says that idris2-lsp cannot load it and offers **Use IDE Mode for This Folder**;
   opening it again shows nothing more. The status reads `syntax only`.
9. **Stop and Restart.** **Idris 2: Stop Language Server**: the status reads `· stopped`, `pgrep`
   lists nothing, hovers show nothing. **Restart Language Server**: one server again.
10. **bamboo's settings.** Add `"idris2-lsp.loglevel": "warning"` to the user settings file: a
    notification offers to copy it; **Copy Settings** sets `idris2.lsp.logSeverity` to `warning`.
    Remove both.
11. **Restricted Mode.** Reopen the folder untrusted (**Workspaces: Manage Workspace Trust**): no
    server starts (`pgrep` lists nothing); nothing in a notification is a link.
