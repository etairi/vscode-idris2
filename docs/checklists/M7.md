# M7 manual checklist

This is the "Manual" test layer of `docs/ARCHITECTURE.md` §12 for milestone M7 (`docs/ROADMAP.md` §5).
Work through it on the packaged extension. It checks what the automated suites cannot: real keys and
clicks, and how the panel looks. No API dispatches a key or reaches into a webview.

**Setup.** A throwaway profile under short `/tmp/vi2-*` paths (F17), with `--shared-data-dir`, and
`code` standing for `"/Applications/Visual Studio Code.app/Contents/Resources/app/bin/code"` on macOS.
Kill only the VS Code processes started this way, and delete `/tmp/vi2-m7c` and `/tmp/vi2-m7c-ws` at the end.

```sh
npm run package                                    # → idris2-language-tools-<version>.vsix
cp -R test/fixtures/workspaces/broken /tmp/vi2-m7c-ws
V=(--user-data-dir /tmp/vi2-m7c/u --extensions-dir /tmp/vi2-m7c/e --shared-data-dir /tmp/vi2-m7c/s --disable-telemetry)
code "${V[@]}" --install-extension idris2-language-tools-*.vsix
code "${V[@]}" /tmp/vi2-m7c-ws
```

1. **The keys.** Trust the folder and open `Clean.idr`. `Cmd+Shift+Enter` (`Ctrl+Shift+Enter` on Linux)
   opens the panel beside the editor, and the cursor stays in the editor. The same key closes it. So
   does `Ctrl+C Ctrl+,` under `chords` (`Ctrl+Alt+I ,` under `prefix`). With the scheme `none`, neither
   key does anything. In a plain text file the key still inserts a line above.
2. **The chat input.** With `Clean.idr` active, focus the Chat input, type a word, and press the key:
   the panel does not toggle.
3. **The goal.** Click into `?vlen_rhs`: `0 a : Type`, `0 n : Nat`, `xs : Vect n a`, a rule, `Nat`,
   before you can look across. Move off the line: *Put the cursor on a hole*. On `append`'s
   declaration: **Generate Definition**.
4. **Look.** Change the colour theme to a light one, a dark one and a high-contrast one: the panel
   stays readable, buttons look like buttons, and a long type wraps without a horizontal scroll bar.
5. **Buttons, with real clicks.** On `?vlen_rhs`: **Proof Search** replaces the hole, **Next** gives the
   next result, undo. **Case Split** on `xs` writes two clauses, undo. **Jump** on `xs` selects it in
   the editor's group, not the panel's. **Refine** with `S` and Enter gives `(S ?vlen_rhs_0)`, undo.
   **Copy** and paste: Markdown with the name, the premises and the goal.
6. **Choices.** On a hole with several Intro answers (`Intro` on a hole of type `Bool`, say) the
   answers are listed in the panel, and **Cancel** changes nothing.
7. **Printing.** Tick *Namespaces*: `Prelude.Nat`, and `idris2.ideMode.fullNamespace` is on in your
   user settings. Untick it. *Implicits* shows the implicit binders where the compiler prints any.
8. **Pin and follow.** **Pin** on `?vlen_rhs`, click elsewhere: the goal stays, **Unpin** ends it. Untick
   *Follow cursor*: the panel stays where it was, and it catches up when ticked again.
9. **The banner.** Type a space under `idris2.checkOnType.enabled` off: the banner appears and nothing
   moves; **Save** saves, and it goes.
10. **Lists.** **All holes**: a click selects the hole in the editor. Break a line so that the file has
    an error: **Messages** lists it, and a click shows it.
11. **Reload.** With the panel open, run **Developer: Reload Window**: the panel comes back with the
    goal at the cursor. Hide it behind another tab in its group and bring it back: nothing was lost.
12. **Text stays text.** Name a hole's type after a string that holds `<img src=x onerror=alert(1)>`, or
    put that text in a comment the compiler quotes in an error: **Messages** shows it literally, and
    nothing runs.
13. **Restricted Mode.** Open the folder without trusting it: the command is not in the palette, and
    a panel left open is gone after a reload.
