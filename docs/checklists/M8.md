# M8 manual checklist

This is the "Manual" test layer of `docs/ARCHITECTURE.md` §12 for milestone M8 (`docs/ROADMAP.md` §5).
Work through it on the packaged extension. It checks what the automated suites cannot: a terminal's
screen, the real Query box, and the one acceptance item that needs two compilers at once.

**Setup.** As in `docs/checklists/M7.md`, with `/tmp/vi2-m8c`:

```sh
npm run package
cp -R test/fixtures/workspaces/simple-ipkg /tmp/vi2-m8c-ws
V=(--user-data-dir /tmp/vi2-m8c/u --extensions-dir /tmp/vi2-m8c/e --shared-data-dir /tmp/vi2-m8c/s --disable-telemetry)
code "${V[@]}" --install-extension idris2-language-tools-*.vsix
code "${V[@]}" /tmp/vi2-m8c-ws
```

1. **Open REPL.** Trust the folder and open `src/Foo/B.idr`. **Idris 2: Open REPL** shows a terminal
   `Idris 2 REPL: vi2-m8c-ws` with the prompt `Foo.B>`. `greeting` prints `"hello!"`. A second Open REPL
   shows the same terminal.
2. **Send.** Select `greeting` in the editor: **Send Selection or Line to REPL** prints it, and the cursor
   stays in the editor. With nothing selected it sends the line. **Type of Selection in REPL** prints
   its type, and **Docs of Selection in REPL** on `shout` its documentation.
3. **Several lines.** Select two lines: they arrive as one, and a `:exec` on the second line of a selection
   does not run by itself.
4. **Reload.** Set `idris2.repl.reloadOnSave`, change `shout` in `src/Foo/A.idr` and save: `:r` appears in
   the terminal and rebuilds. `greeting` shows the change.
5. **History.** Without `rlwrap`, the Up arrow prints `^[[A`. With `rlwrap` on `PATH` (`brew install
   rlwrap`, then a new REPL), the Up arrow brings back the last line and the left arrow moves. `:q` ends
   it, and Open REPL starts another.
6. **Query.** **Idris 2: Query…**: type `:t gre`, choose `greeting` in the list, then the first item,
   **Run**: the channel `Idris 2 Query` shows `> :t greeting` and its type, and the cursor stays in the
   editor. `:exec main` is refused with a notification, and `1 + 1` answers `2`.
7. **Two compilers.** With the REPL open and a program run there (`:exec main` of a module that has one),
   hover over a name in the editor: the checking compiler answers. They are separate processes.
8. **Lenses.** Add `-- >>> 1 + 1` and `-- >>> :t greeting` to a file: **Run** writes the answer beneath, a
   second Run replaces it, and Undo takes it back. **Run all (2)** asks first, and says how many.
9. **Colour.** A long `:doc` answer stays a comment in the file: the whole of it is coloured as a comment.
10. **Restricted Mode.** Open the folder without trusting it: no lens, the commands are not in the palette,
    and a keybinding of yours to them says so.
